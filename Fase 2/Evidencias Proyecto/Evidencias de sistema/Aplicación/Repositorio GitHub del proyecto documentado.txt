Qué es
------
Sistema que detecta quiebres de stock en góndolas de alimentos no
perecibles a partir de una foto: corrige la imagen con OpenCV, segmenta
la góndola y sus repisas, detecta los productos con YOLO26 y alerta
cuando el espacio libre de la góndola completa es igual o mayor al 30%.
Incluye una aplicación web Django con tres perfiles (Administrador, Jefe
de Salón y Reponedor).

Cómo ejecutarlo (resumen; el detalle está en el README)
--------------------------------------------------------
1. git clone https://github.com/marianapeachy/capstone.git
2. Crear un entorno virtual con Python 3.12 o superior e instalar
   requirements.txt.
3. Pruebas: pytest tests/
4. Aplicación web en desarrollo, con la variable DJANGO_DEBUG=1:
   python manage.py migrate y luego python manage.py runserver
   (http://localhost:8000). En un servidor, con Docker:
   docker compose up --build, con un archivo .env (ver el instructivo
   del plan de instalación).
